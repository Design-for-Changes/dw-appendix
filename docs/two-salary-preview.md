# 二給与モデル・検証版

`?model=v4` は従来の生成系列ではなく、`src/model-v4/simulatorPreview2025.mjs`から計算本体をブラウザ内で直接実行する。`?model=legacy` は比較用の旧版。生成済みの給与別結果JSONやサーバーAPIを必要としない。`npm start`、`npm run build`の通常手順を使う。

両親45歳、2025年の固定月給・週20時間・千葉支部・介護・厚年・一般事業雇用保険、前年12月を含む健介厚翌月控除と雇用保険当月控除という架空条件を固定する。国税・本人保険は2025年、住民税と別掲森林税は2026年度、国二手当・通所は2026年8月。Y*はこの月を12倍した研究指標で、実際の年間現金収支ではない。

確認済み架空3点はA360万/B120万円で、指標は4,855,724／4,657,004／5,597,424円。第3例は7歳児が国児福適合、10歳児が非該当で、特児は各1級の別認定。児の障害・受給者・税扶養・保険扶養・通所決定は別の架空記録を入力する。給与順位から認定を切り替えない。

確認済み一点モードは給与変更時の認定を持ち越さず、指標と給付を未算定にする。A/B認定を明示的に仮定した条件付きモードだけ、選んだ枝の算術値を返す。法6条加算・未接続所得などで枝が定まらなければ保留。B受給枝が同額でも確認済みへ格上げしない。子の健康保険扶養の再認定・将来見込は別審査で、実認定未確認と表示する。

範囲はA117〜900万円（B120万円固定）またはB117〜840万円（A360万円固定）、3万円刻み。117万円は定常就業条件外。0円・未整除点・範囲外を保険料0や補間で埋めない。低所得の別資格モデル、健康保険異動、全域1万円格子はこの接続に含めない。

医療自己負担・M01、N04費用／補填、市独自手当、児童手当等の未採用費目、未選択政策は主指標に含めず、効果0とも扱わない。旧版と年次・費目・資格条件が異なる。

給与B123万円の独立算術：B健介厚暦年185,190円＋雇用6,921円＝192,111円、A554,445円と合計746,556円。税51,500＋森林2,000、国税0、条件付き月額58,450＋16,560−4,600を用いるとY*=4,874,864円。確認済み一点モードの同給与は認定未確認のため未算定。

新接続の独立試験は `node --test tests/model-v4/simulatorPreview2025.test.mjs tests/model-v4/sha256.test.mjs`、画面を含む既存試験は `CI=true npm test -- --watchAll=false --runInBand`。ハッシュのブラウザ互換化は条件識別子のSHA256だけで、税・保険・給付の数式を変えない。

`research-preview-mobile.html`は同じアプリを390px幅で実行する手書きの検証枠。スマホ幅の再計算とCSSを確認できるが、実機キーボードの確認とは区別する。
