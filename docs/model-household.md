# モデル世帯と採用値

## モデル世帯シミュレーター（Web Appendix D）

夫婦はともに45歳、各人の給与収入を独立に年0～1,500万円（1万円刻み）で変える。子どもは1～3人とし、年齢・障害要件・通所負担を児童別に設定する。同月の通所負担を合算して世帯上限を適用する。医療費助成・医療自己負担と、就学奨励費・その対象実費は算入しない。これらが実際に0円という意味ではない。

本試算の計算仕様は `paper-2029`。居住・勤務は船橋市、正の給与は12等分し、賞与・通勤手当なし、給与以外の加入条件を満たすと仮定する。夫婦とも給与0円の原点は計算しない。社会保険料の年度・参照料率は[社会保険料の条件](model-social-insurance.md)を参照。

主試算では、隣接する給与点で世帯収支が低下した場合に下落幅と回復必要増収を求める。その後の考察では、下落の有無にかかわらず制度の判定が切り替わる区間を調べる。同じ所得割上の境界でも、船橋市の重度障害者医療と子ども医療のように、別の制度がカバーすれば窓口負担が増えるとは限らない。就学奨励費は制度所定の収入額と需要額で判定し、欠けている場合は額面給与から区分を推定しない。いずれも主試算の金額とは別に扱う。

以下は旧版の結果を再現するために残した設定であり、現行シミュレーターの初期条件ではない。

## 旧版の提示モデル世帯
- 世帯主45歳、配偶者45歳・所得0円。世帯主給与を200〜1500万円で掃引する。
- 障害児の人数、年齢、障害区分、等級、対象制度は提示ケースごとに定義する。
- 税・社会保険シナリオ：`S3_R8_R9`。
- 検証用の単身ケースA〜G・V系列は回帰確認のため残す。

## 扶養人数・障害区分の扱い
- 特別児童扶養手当と障害児福祉手当等の限度額判定に渡す扶養人数は、扶養親族等の実人数＋法定加算（特定扶養・老人扶養等）のみ。障害を理由とする人数加算は含めない。
- A/E/F/Gの障害児は10歳のため、特定扶養・老人扶養等の法定加算はゼロ。
- 障害区分は判定所得の控除側には残す。特児判定では給与所得控除後の調整10万円、固定の社会保険料相当8万円、特別障害者40万円控除を使う。住民税側では同居特別障害者53万円控除を使う。
- 障害児福祉手当の扶養義務者判定所得も手当方式を使う。実社会保険料・基礎控除・所得金額調整控除・住民税用の同居特別障害者控除53万円は使わず、給与所得控除後の調整10万円、固定の社会保険料相当8万円、特別障害者40万円控除を使う。
- 障害福祉サービス利用料、M01、N04の境界は計算コアから算出し、fixtureで回帰する。

## 既にモデルに載っている制度
特別児童扶養手当（所得制限・扶養人数判定）、障害児福祉手当／特別障害者手当（本人・扶養義務者の二重所得制限）、障害福祉サービス利用者負担（応能負担、住民税所得割ベース）、障害基礎年金、児童扶養手当、児童手当。税・社保（給与所得控除・基礎控除〔所得税/住民税別〕・社会保険料〔40歳未満/以上〕・各種所得控除）。

## 費用軽減制度

### M01　重度心身障害者(児)医療費助成
- 判定：世帯の住民税所得割。**所得割23万5千円以上で助成対象外**。
- 従来モデルの設定：対象内の自己負担を0と近似し、所得割が閾値以上になると代表年額を自己負担へ戻す。船橋市の実制度の対象内負担（課税は通院1回・入院1日300円）や、子ども医療費助成への切替えは未反映である。
- **モデルに入力している代表年額：149,531円/人・年（≒月約12,500円）**。伊勢原市の平成29年度実績を扱う会議録（2018年9月10日）にある記載値。全年齢混在の参考平均であり、障害児だけの分布を示すものではない。
- 比較用の平均値：伊予市 約167,929円/年（R3実績）。自治体間の平均値の違いであり、個人・世帯の費用分布や信頼区間ではない。
- 149,531円は原典会議録の記載値である。同資料に併記された助成総額2億2,218万円と1,466人からの単純除算は約151,555円となり、一致しない。分母・費目の対応は未確定のため、再算出した値と表現しない。
- この助成額平均はM01喪失後の自己負担増そのものではない。子ども医療費助成等による代替を含む反事実の設定とは区別する。現公開系列は従来設定を保持しており、実効自己負担差の再推計は未反映である。
- 出典：伊勢原市議会・教育福祉常任委員会会議録（平成29年度決算）／伊予市事務事業評価シート（R3-1110）。

### N04　特別支援教育就学奨励費

#### 既存3ケース：再現用legacy

- `programs.n04EducationProfile` を指定しない既存系列は、従来の年額72,945／36,473／0円を保持する。これは学用品費上限11,640円と川崎市R8小学部の食材料費相当61,305円を合成した条件値であり、保護者実支出・平均支給額ではない。
- 従来値の出典表記には学校種の混在がある。船橋市の案内は小中学校の特別支援学級等を対象とし、特別支援学校小学部の満額・半額構造の直接根拠ではない。R8給食負担軽減後の家計差も反映していない。
- 需要額の旧計算も再現用に保持する。期末一時扶助は旧表に3・4人値しかなく、5人以上の新研究に旧表を流用しない。現在の値を新研究の確定条件と呼ばない。

#### 旧設計で検討した研究条件：学校種・費目・需要測定を分離

- オプション入力 `programs.n04EducationProfile` は、2026年度・特別支援学校小学部・通学生に限定する。通常年とし、新入学用品・修学旅行費は毎年計上しない。
- 採用給付費目は学用品・通学用品購入費のみ。対象実費E（円/児童・年）を入力し、第1区分 `min(E, 11,640)`、第2区分 `min(E/2, 5,820)`、第3区分0円とする。[R8公式限度額表](https://www.sankakuyama.hokkaido-c.ed.jp/wysiwyg/file/download/1/383)の上限であり、平均額ではない。
- 比較条件ではE=11,640円の上限到達を仮定する。金額の小さい実費を指定することもできる。円未満の実支払端数処理は未確認のため、費目計算は数式上の額を丸めず返す。本比較のEは整数で半額も整数になる。
- 給食費は給付額に加えない。R8給食負担軽減との調整を未確認のまま、61,305円を所得制限後の家計負担増へ戻さない。給食を含む教育費全体を網羅した試算ではない。
- `annualEligibleExpenseYen` / `grossExpenseAnnualYen` は採用費目の実支出総額（円/世帯・年）、`annualWan` は補助額（万円/世帯・年）。給付と実費を別々に家計計算へ渡し、費用を差し引かず給付だけを上積みしない。
- 支弁区分は、世帯の測定収入額とN04の測定需要額の比が1.5未満／2.5未満／それ以上で判定する。[施行令第2条](https://laws.e-gov.go.jp/law/329CO0000000157)。これは採用学用品費の補助率であり、N04の全費目が第3区分でゼロになるという意味ではない。

#### N04需要額の必須入力と未確定ゲート

- 需要額Dは就学奨励費の支給額でも教育実支出でもない。[測定要領III～V](https://www.dokyoi.pref.hokkaido.lg.jp/fs/9/7/1/2/4/0/4/_/R7%20%E5%8F%8E%E5%85%A5%E9%A1%8D%E3%83%BB%E9%9C%80%E8%A6%81%E9%A1%8D%E3%81%AE%E6%B8%AC%E5%AE%9A%E8%A6%81%E9%A0%98.pdf)により、2026年度は前年12月末（2025-12-31）の世帯構成・保護基準を用いる。R8年度内の新しい生活保護額へ自動置換しない。
- 新実装は第1類・逓減率・第2類・冬季加算を1級地2、冬季VI区、1～5人の確認範囲で参照する。5人では逓減率0.59、第2類49,180円/月、冬季加算4,710円/月。[千葉県の人数別表](https://www.pref.chiba.lg.jp/kenshidou/shien/book/seikatsuhogo.html)。6人以上は未確認範囲として停止し、9人値への丸めや外挿をしない。
- 期末一時扶助、経過的加算、特例加算、障害者加算、母子加算、学校長指定教材代、前年国予算単価による学校給食費、前年通学費、住宅扶助測定額を、`needMeasurement` の別項目として明示入力する。生活保護世帯の児童養育加算や常時介護に関する額をN04へ自動移植しない。
- 教育扶助の基準額は、N04給付対象児d人だけでなく、需要測定の教育扶助対象児童数を別に指定する。本条件案では全児童n人が小学校段階にある。教材代・給食予算額も世帯合計額を指定する。
- 必須金額が `null` / 未指定の場合は `N04_CONFIG_INCOMPLETE` とし、黙って0円として計算しない。明示的な徒歩通学0円などの仮想条件とは区別する。原典値・仮定値の根拠は `inputEvidence` に残す。
- 文科省が示す専用の保護基準額等早見表への対応、障害者加算の採用範囲、前年給食国予算単価等が未確定の間は、条件定義と実行可能な計算結果を区別する。一般生活保護表からの推測だけで制度式の完全再現を主張しない。

## 旧設計の固定条件索引（279条件）と従来ケースの分離

- `scripts/generate-revision-scenarios.mjs` は `public/data/research/revision-scenarios.json` を生成する。従来3ケースの入力・結果を置換しない。新条件の税・手当キーは `S4_R8_FINAL`。
- 子ども総数n=1～3、障害児数1≦d≦nとし、各障害児にA（特児2級）、B（特児1級）、C（特児1級＋障害児福祉手当）という所得制限適用前の資格組合せを仮定する。医学的重症度3階層、典型世帯、全障害児の網羅的分類ではない。
- 全児童7歳、障害児は同じ特別支援学校小学部・通学条件とする。交換しても計算条件が変わらない人数構成として数えると、n別に3／9／19構成、計31構成となる。年齢・利用条件等が違えばこの交換可能性は使えない。
- 税法上の障害区分とN04障害者加算は給付資格とは別のモデル条件である。本比較の税法条件はAを一般、B/Cを同居特別と明示して置く。特児等級から税法区分が自動決定するという主張ではない。N04加算額は別入力で保持し、未確定なら計算しない。
- 配偶者給与0／200／400万円、児童1人の月額R=4,600／10,406／37,200円の3条件を掛け、31×3×3=279世帯条件を定義する。Rはサービス総費用ではなく月額上限適用前の定率負担相当額。毎月同額・12か月、利用児のRを合計してから世帯上限を適用する仮定である。
- 3つのRは構造比較の仮定的条件であり、平均・中央値・分位点ではない。10,406円も旧観測値との接続のためRへ置いた仮定であり、東京都調査が観測した上限適用前Rではない。
- 横軸は世帯主給与200～1,500万円・1万円刻み（1,301点）。配偶者給与を変える比較は世帯給与合計も変える。同一給与総額を夫婦間で配分する効果だけを分析するものではない。
- 医療費助成は新条件の定量試算から除く。人口ウェイト、有病率、逆転世帯数、財政影響、政策的最適性は推計しない。
- 生成直後の `result: null` は計算未収録を表す。`blocked` はN04等の必須入力未確定を表し、所得逆転がないという結果ではない。原典・条件が確定してから結果を生成する。

## 数値ルール
- 語感で数字を足さない。すべて一次資料に紐づける（上の出典を維持）。
- 児童分が取れず全年齢混在値を使う等の代替は、本文・注に必ず明記する（M01がその例）。
