# 使用データ

Web Appendixの「使用データ」タブは、本文で用いた抽出データと採否を再確認できるようにするための補足資料である。

## 表1　e-Gov法令検索による抽出母集団と採否

- 基準日：2026年6月30日
- 対象：現行法律
- 検索語：「障害者」「障害児」「特別支援学校」
- 検索範囲：本則（MainProvision）
- 統合方法：各検索結果を法令ID単位で重複除去した和集合
- 抽出数：186件
- 採用数：8件

取得データは `public/data/research/egov-law-screening.json` に保存する。
`npm run fetch:egov-screening` を実行すると、e-Gov法令API Version 2から同じ手順で再取得できる。

## 本文表Ⅱ-1　障害児世帯の可処分所得に作用しうる法律

表1の186件から、障害を要件として障害児世帯の手当・給付、利用者負担、控除・減免等に直接作用しうる法律を採用した結果を示す。

## 本文表Ⅱ-2　自治体制度の類型と普及度

政令指定都市20市および人口50万人以上の中核市6市を対象とした制度調査を、制度内容に基づく19類型に整理した。公開用データは `public/data/research/municipal-program-types.json` に保存する。
