# モデル世帯と採用値

## 提示モデル世帯
- 世帯主45歳、配偶者45歳・所得0円。世帯主給与を200〜1400万円で掃引する。
- 障害児の人数、年齢、障害区分、等級、対象制度は提示ケースごとに定義する。
- 税・社会保険シナリオ：`S3_R8_R9`。
- 検証用の単身ケースA〜G・V系列は回帰確認のため残す。

## 扶養人数・障害区分の扱い
- 特別児童扶養手当と障害児福祉手当等の限度額判定に渡す扶養人数は、扶養親族等の実人数＋法定加算（特定扶養・老人扶養等）のみ。障害を理由とする人数加算は含めない。
- A/E/F/Gの障害児は10歳のため、特定扶養・老人扶養等の法定加算はゼロ。
- 障害区分は判定所得の控除側には残す。特児判定では給与所得控除後の調整10万円、固定の社会保険料相当8万円、特別障害者40万円控除を使う。住民税側では同居特別障害者53万円控除を使う。
- 障害児福祉手当の扶養義務者判定所得も手当方式を使う。実社会保険料・基礎控除・所得金額調整控除・住民税用の同居特別障害者控除53万円は使わず、給与所得控除後の調整10万円、固定の社会保険料相当8万円、特別障害者40万円控除を使う。
- 障害福祉サービス利用料、M01、N04の境界は計算コアから算出し、fixtureで回帰する。

## 既にモデルに載っている制度
特別児童扶養手当（所得制限・扶養人数判定）、障害児福祉手当／特別障害者手当（本人・扶養義務者の二重所得制限）、障害福祉サービス利用者負担（応能負担、住民税所得割ベース）、障害基礎年金、児童扶養手当、児童手当。税・社保（給与所得控除・基礎控除〔所得税/住民税別〕・社会保険料〔40歳未満/以上〕・各種所得控除）。

## 費用軽減制度

### M01　重度心身障害者(児)医療費助成
- 判定：世帯の住民税所得割。**所得割23万5千円以上で助成対象外**。
- 崖の機序：対象内は助成で自己負担が小さい（船橋市：非課税0／課税は通院・入院1回∕日300円）。所得割が閾値を超えると助成が消え、肩代わりされていた医療費が自己負担へ戻る＝下向きの崖。
- **崖の高さ（採用値）：受給者1人当たり助成額 149,531円/年（≒月約12,500円）**。伊勢原市・平成29年度決算（医療証交付者1,466人・助成総額2億2,218万円）。全年齢混在の参考代表値（児童分の公表値は確認できず、その旨を本文に明記）。
- 感度分析：伊予市 約167,929円/年（R3実績）。**崖の高さは年約15〜17万円（月約1.2〜1.4万円）**に分布。
- 出典：伊勢原市議会・教育福祉常任委員会会議録（平成29年度決算）／伊予市事務事業評価シート（R3-1110）。

### N04　特別支援教育就学奨励費
- 判定：世帯全員の所得を**生活保護基準の需要額**と比較し、支弁区分（3段階）を決める。
- 区分境界：**生活保護基準の1.50倍（第1／第2）・2.50倍（第2／第3）**。
- 崖の機序：支弁区分が上がると補助割合が段階的に下がる（第1満額／第2半額／第3なし）＝段差。
- **補助額（小学部・年額。採用値）：第1 72,945／第2 36,473／第3 0**。
  - 内訳｜学用品・通学用品購入費：第1 11,640／第2 5,820／第3 0。
  - 内訳｜学校給食費（実費水準＝食材料費相当、川崎市令和8年度）：第1 61,305／第2 30,653（×1/2）／第3 0。
  - 断り：給食費は就学奨励費の補助対象となる実費水準であり、自治体の給食無償化後の実徴収額とは区別する。半額値はモデル内計算（原典年額×1/2）。
- 収入額と需要額をコアで計算し、1.5倍・2.5倍の支弁区分を動的に判定する。
- 出典：文部科学省（2018）「特別支援教育就学奨励費負担等説明資料」。学用品単価は名古屋市・清瀬市等の基準額。給食費は川崎市（実費水準）・横浜市（制度額）。
- 感度分析：中学部（第1 22,740／第2 11,370／第3 0＋給食）、給食費の堅め代表値（横浜市 小50,600／中62,700）。通学費は第3区分でも実費支給のため崖の主変数から外す。

## 数値ルール
- 語感で数字を足さない。すべて一次資料に紐づける（上の出典を維持）。
- 児童分が取れず全年齢混在値を使う等の代替は、本文・注に必ず明記する（M01がその例）。
