## 新条件の未確定範囲

N04は支弁区分を決める需要額と、費目別の対象実費・支給額を分離した。新プロフィールでは教育実費を可処分所得から引き、補助額を加える。必須入力が未確定なら `N04_CONFIG_INCOMPLETE` として停止する。専用の保護基準額等早見表、加算の採用範囲、前年の給食参照予算単価等を推測で埋めない。

R_i＝4,600／10,406／37,200円は制度反応を比較する仮定的条件である。10,406円は既存の東京都の事後負担平均との接続をみる参照値であり、上限適用前R_iの平均・中央値ではない。279条件は典型世帯・人口分位ではなく、人口ウェイトや財政影響は推定しない。

探索的調整例の連続化と、各給与点での現行制度より有利か否かは別に評価する。新比較関数のBは掃引範囲で得られた最大現金給付であり、制度上の満額・障害追加費用の推定値ではない。最適性や全世帯の改善を主張しない。

## 検証の版管理

旧 `fixtures/cases.json` と `fixtures/refactor-contract.json` は保存する。今回の制度式是正後の回帰値は `display-corrections-20261115.json` と `calculation-contract-20261115.json` に分けた。旧結果への一致は今回の正しさの条件ではない。

原典の境界・具体例の単体検証、独立oracle、計算コアと表示データの照合、全返却値の回帰ハッシュ、表示テストを別々に行う。新しい回帰ハッシュは出力固定の検証であり、全制度・全世帯の法令適合を保証しない。

研究新系列は両親・給与所得・子ども7歳を対象とする。親の障害年金、養育費・公的年金調整等を含む児童扶養手当の全所得判定、暦年の所得ラグ、月別利用変動、医療の他公費調整は未完成又は対象外である。
