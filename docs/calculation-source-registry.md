# 計算根拠と確度

## 対象年度

提示ケースは `S3_R8_R9` を用いる。所得税、社会保険料、障害関連手当は令和8年度の公表値、
住民税は対応する年度の税額計算を使う。給与は200万円から1400万円まで1万円刻みで掃引する。

## 確度

- `strict`：法令・行政資料の算式または額をコアで直接計算する。
- `representative`：公表実績から得た代表年額を使う。
- `provisional`：モデル入力または未確定の費目を含む。

## 主要計算

### 税

- 給与所得控除：国税庁の令和8年分区分式。850万円超は195万円上限。
- 所得税：課税所得を千円未満切捨て後、速算式で計算。
- 住民税：課税所得を千円未満切捨て後、所得割、調整控除、均等割を計算。

### 社会保険

東京都の令和8年度料率を使う賞与なし・率ベース年額近似。算式と900万円点の独立検算は
`docs/model-social-insurance.md` に記載する。

### 現金給付

特別児童扶養手当と障害児福祉手当は、通常の課税所得とは異なる制度固有の判定所得を用いる。
基礎控除引上げ相当額10万円、社会保険料控除8万円固定、障害者控除等を個別に返す。

### M01

所得制限23万5千円は制度事実。医療費自己負担の軽減効果は伊勢原市の平成29年度実績から
算出した149,531円/人・年を代表値として使うため、確度は `representative`。

### N04

収入額と生活保護基準による需要額を各給与点で計算する。住宅扶助56,000円と小学部のモデル年額を
含むため、確度は `provisional`。固定給与境界は使わない。

### 障害児通所支援

負担上限は世帯単位の最大値を1回だけ使う。一般2は制度上限37,200円ではなく、東京都の令和6年度
調査による月額10,406円を代表負担として `min(10,406円, 制度上限)` に適用する。
