## 表A1　主な制度の所得判定・変動方法

`public/data/research/income-assessment-rules.json` に、判定単位・主たる判定対象・その他の判定対象・所得指標・変動方法を7列、10行で収録する。Web Appendixの「所得判定・変動方法」タブで表示し、直接参照は `#income-assessment`。自治体制度の具体例は船橋市である。

この制度横断の比較資料と、シミュレーターに実装された計算対象の範囲は同一ではない。モデル条件・計算コアは別途参照する。本文から移設した詳細を保持し、市別の調査マトリクスは含めない。

## 表A2　e-Gov法令検索による抽出結果と選定候補

- 基準日：2026年11月13日
- 対象：現行184法律
- 検索語：「障害者」「障害児」「特別支援学校」
- 検索範囲：本則（MainProvision）
- 統合方法：各検索結果を法令ID単位で重複除去した和集合
- 除外した法律は、除外理由ごとの表に整理する。残る法律は個別検討する候補として示す。

取得データは `public/data/research/egov-law-screening.json` に保存する。
`npm run fetch:egov-screening` はe-Gov法令API Version 2から検索結果を再取得し、`private/research/egov-law-search.json` へ保存する。検索だけで採否を確定せず、公開済みの個別理由を上書きしない。

候補への収録はモデル世帯への試算採用を意味しない。所得制限の有無ではなく、障害を要件として障害児世帯の可処分所得に作用する規定の有無を検討する。そのうえで、就労・職域・災害・特定の障害原因等を前提とするものなどを除外する。

## 調査対象・参照資料

`public/data/research/municipal-source-list.json` に対象26市の基本案内に加え、実際に使用したPDF本体・個別制度案内・要綱を収録する。市別掲載212件、重複URLを除くと206件。「調査対象・参照資料」タブで表示し、直接参照は `#municipal-sources`。

対象条件は政令指定都市と人口50万人以上の中核市。2026年1月1日現在の住民基本台帳人口総計（日本人住民・外国人住民の合計）を採用し、現行の指定政令と照合した結果、政令市20市、中核市6市となった。

最終確認日は資料の記録に従い、記録がないものは未記録として表示する。ページ更新日を最終確認日に代用しない。資料の版・改訂情報も記録にある範囲だけ示す。

26市の調査結果の公開範囲は市名・人口基準・資料名・版・公式URLまでとする。26市を横断する類型該当、制度名対応、児童への適用判定、集計根拠は非公開の改稿ノートで管理する。この市別マトリクスをリポジトリ、`public/`、ビルド成果物には保存しない。非表示のタブやダウンロードリンクを外すだけでは非公開にならない。上記の表A1は、別途公開する全国制度と船橋市例の比較資料であり、市別調査マトリクスではない。

`node scripts/verify-municipal-sources.mjs` は対象数・区分・公式ドメインと公開データの項目範囲を検証する。リンク先本文の継続的な正しさや、全制度の適用確認を保証する検証ではない。
