# 計算根拠と採用条件

## 対象年度

従来3入力の参考計算は `S3_R8_R9` の旧税表を使う。改稿用の条件Gは `S4_R8_FINAL` とし、2026年分年末確定所得税・同年所得に基づく2027年度住民税・R8手当額を同じ給与点に適用する静的比較である。実際の所得年ラグは再現しない。給与は200万円から1500万円まで1万円刻みで掃引する。制度式是正と未確認範囲は[更新記録](calculation-update-20261115.md)を参照。

## 内部の採用条件ラベル

- `strict`：法令・行政資料の算式または額をコアで直接計算する。
- `representative`：公表実績から得た代表年額を使う。
- `provisional`：モデル入力または未確定の費目を含む。
- `conditional`：明示した仮定的利用額等に制度式を適用する。実測の代表値ではない。

これらは統計的信頼度や正しさの確率を表すものではない。

## 主要計算

### 税

- 給与所得控除：国税庁の令和8年分区分式。850万円超は195万円上限。
- 所得税：課税所得を千円未満切捨て後、速算式で計算。
- 住民税：課税所得を千円未満切捨て後、所得割、調整控除、均等割を計算。

### 社会保険

東京都の令和8年度料率を使う賞与なし・率ベース年額近似。算式と900万円点の独立検算は
`docs/model-social-insurance.md` に記載する。

### 現金給付

特別児童扶養手当と障害児福祉手当は、通常の課税所得とは異なる制度固有の判定所得を用いる。
基礎控除引上げ相当額10万円、社会保険料控除8万円固定、障害者控除等を個別に返す。

### M01

従来条件の所得制限23万5千円は制度事実。旧医療条件の軽減効果には伊勢原市の平成29年度実績に記載された149,531円/人・年を使い、ラベルは `representative`。
助成総額と人数からの単純除算とは一致せず、この平均を助成喪失時の自己負担増とみなす設定も別途検討を要する。
改稿用279条件は医療助成を計算しない。影響がないと確認した意味ではない。

### N04

従来条件は住宅費56,000円と旧合成支給年額を含む `provisional`。新プロフィールでは需要額測定と費目別補助額を分離し、教育実費を引いて補助を加える。需要額測定の必須入力が未確定の場合は計算停止とする。専用早見表等を確認せず、旧値を新研究の確定値へ流用しない。

### 障害児通所支援

従来入力は最大値方式と一般2の月額10,406円という旧条件を再現する。原資料の単位は児童であり、複数児世帯の平均や上限適用前利用額の平均ではない。新入力 `programs.serviceUse` では、児童別R_iの合計に世帯上限を適用する。R_iを所得前後で固定し、仮定的利用条件として `conditional` を付ける。税徴収額と、年少扶養控除等の相当税額を補正した福祉判定用所得割額は別の返値にする。
