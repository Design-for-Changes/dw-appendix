## 表A3　計算内容と関数の対応

Web Appendix F「関数資料」に、計算の流れと関数の対応、名前付き関数一覧を掲載する。直接参照は従来と同じ `#calculation-functions`。対応表の関数名はページ内の説明へ、関数説明は対応する処理行とソースへリンクする。関数はファイルと階層名の完全IDで識別し、同名関数を区別する。深いURLからの再読込にも対応し、フィルターで宛先が非表示の場合は移動時に解除する。

## 表A1　給付・負担関連制度の所得区分・判定方法（Web Appendix C）

`public/data/research/income-assessment-rules.json`（schema 2.0.0）に、所得による区分・制限の有無を追加した8列44行を収録する。国9法律に対応する20行と、船橋市をサンプルとする19類型・24行に分け、同じ法律・類型内の個別制度を区別する。直接参照は `#income-assessment`。国制度／船橋市、所得条件あり／なし／未確認、キーワードで絞り込める。

各行の詳細欄に、児童への適用、併給・代替、確認範囲、公式出典と該当箇所、最終確認日を保持する。所得制限がなくても所得に応じた負担区分があれば「あり」とし、案内に記載がないだけの場合は「未確認」とする。所得条件は29行があり、11行がなし、4行が未確認。未確認は船橋市の個別制度自体が未確認のM16～M19で、不実施を意味しない。M06の公園施設減免は条例・規則を確認した具体例に限定し、全公共施設の同一基準を保証しない。

障害を要件としない普遍的制度、国の成人専用・入所制度は対象外。国の小児慢性特定疾病医療は疾病要件の制度として抽出対象から区別し、市独自制度M13の調整関係として参照する。市の住宅改造助成の年齢条件、市児童手当の国手当受給資格者に対する適用除外、受付終了した小児指定疾病助成の取扱いを注記する。

この確認表とシミュレーターの計算対象は同一ではなく、表の更新だけでは計算式・代表値・出力を変更しない。公開データには26市を横断する市別マトリクスを含めない。`node scripts/verify-income-assessment.mjs` はスキーマ・9法律/19類型の対応・公式出典・公開範囲等を検証するが、未確認を検証済みに変更するものではない。

## 表A2　e-Gov法令検索による抽出結果と採否

- 基準日：2026年11月13日
- 対象：現行184法律
- 検索語：「障害者」「障害児」「特別支援学校」
- 検索範囲：本則（MainProvision）
- 統合方法：各検索結果を法令ID単位で重複除去した和集合
- 採用9法律を先に示し、除外175法律は理由別の折りたたみ表に整理する。検索時は該当する表を開く。

取得データは `public/data/research/egov-law-screening.json` に保存する。
`npm run fetch:egov-screening` はe-Gov法令API Version 2から検索結果を再取得し、`private/research/egov-law-search.json` へ保存する。検索だけで採否を確定せず、公開済みの個別理由を上書きしない。

法律の採用とモデル世帯の試算対象の選定は区別する。所得制限の有無だけで採否を決めず、障害を要件として障害児世帯の可処分所得に作用する規定を対象とする。成人向け措置、措置入院の費用負担、過年度の給付額改定の特例等の除外理由は、法令ごとに記録する。

## 調査対象・参照資料

`public/data/research/municipal-source-list.json` に対象26市の基本案内に加え、実際に使用したPDF本体・個別制度案内・要綱を収録する。市別掲載212件、重複URLを除くと206件。「調査対象・参照資料」タブで表示し、直接参照は `#municipal-sources`。

対象条件は政令指定都市と人口50万人以上の中核市。2026年1月1日現在の住民基本台帳人口総計（日本人住民・外国人住民の合計）を採用し、現行の指定政令と照合した結果、政令市20市、中核市6市となった。

最終確認日は資料の記録に従い、記録がないものは未記録として表示する。ページ更新日を最終確認日に代用しない。資料の版・改訂情報も記録にある範囲だけ示す。

26市の調査結果の公開範囲は市名・人口基準・資料名・版・公式URLまでとする。26市を横断する類型該当、制度名対応、児童への適用判定、集計根拠は非公開の改稿ノートで管理する。この市別マトリクスをリポジトリ、`public/`、ビルド成果物には保存しない。非表示のタブやダウンロードリンクを外すだけでは非公開にならない。上記の表A1は、別途公開する全国制度と船橋市例の比較資料であり、市別調査マトリクスではない。

`node scripts/verify-municipal-sources.mjs` は対象数・区分・公式ドメインと公開データの項目範囲を検証する。リンク先本文の継続的な正しさや、全制度の適用確認を保証する検証ではない。
